KGPanel Setup Guide

THE easy version — every single step, with real pictures from a working install.

Works on Linux, macOS, and Windows. Follow the section for YOUR computer. If a screenshot doesn't look exactly like yours, don't panic — your screen just has different names on it. The buttons are in the same place.

★Words you need to know

Panel
The website part. This is what you (and your friends with permission) open in a browser to control your games.
Wings
The helper program that runs on the actual game computer. The panel talks to wings; wings starts/stops the games.
Node
Any computer that runs games. It must have Docker installed (a free program that keeps each game in its own safe box).
Egg
A recipe/template for a game — which image to use, how to start it, which ports it needs. One egg = one game type (PalWorld, Minecraft, …).
Port
A numbered door on a computer (like 8211 for PalWorld). Players need the IP + port to join your game.
IP address
Your computer's address on the network, like 10.15.34.121.
Domain
A name people type instead of an IP, like panel.yourname.com.
SSL / HTTPS
The padlock 🔒 in the browser. Free and automatic with KGPanel when you use the domain step (Step 10).
Terminal
The black window where you type commands. On Windows: open "PowerShell". On Mac/Linux: open "Terminal".
Docker
A free program that runs each game "in a box" so games can't mess up each other or your computer.

STEP 1Download KGPanel

Go to the releases page: https://github.com/MrKnuckls/kgpanel/releases

Download the TWO programs that match your computer:

Your computerDownload this for the panelDownload this for wings
Windowskgpanel-windows-amd64.exewings-windows-amd64.exe
Linux (most servers)kgpanel-linux-amd64wings-linux-amd64
Mackgpanel-darwin-amd64wings-darwin-amd64
The ".exe" ones are for Windows. The ones without .exe are for Linux/Mac. If your computer is "arm64" (Apple M-series, some mini PCs) get the arm64 ones.

Put both files in a folder you can find, e.g. C:\kgpanel (Windows) or ~/kgpanel (Linux/Mac).

Don't know if your computer is amd64 or arm64? On Windows run echo %PROCESSOR_ARCHITECTURE% in PowerShell. If it says AMD64 get amd64; if ARM64 get arm64. On Linux/Mac run uname -m.

STEP 2Start the panel

The panel program makes one secret number (a "secret") and needs it every time it starts. Make one now — keep it somewhere! You need it again after every restart (or save it in the service file below).

Do this once: open your terminal and run openssl rand -hex 32 — copy the long number you get and paste it into a notepad. That's your secret.
🪟 WINDOWS — start the panel
  1. Open PowerShell (press the Start button, type "PowerShell").
  2. Go to your folder: cd C:\kgpanel
  3. Start the panel with your secret (put YOUR number in):
    ./kgpanel-windows-amd64.exe --listen :8080 --data .\data --secret YOUR-LONG-SECRET-HERE
  4. Leave this window OPEN — closing it stops the panel.
  5. To make it always-on (survives restarts): the easy way is Docker or NSSM — see docs/INSTALL.md §14.
🐧 LINUX / MAC — start the panel
  1. Open Terminal.
  2. Move the program somewhere permanent and make it runnable: 
    sudo install -m 0755 kgpanel-linux-amd64 /usr/local/bin/kgpanel
sudo mkdir -p /var/lib/kgpanel
  3. Start it with your secret:
    sudo kgpanel --listen :8080 --data /var/lib/kgpanel --secret YOUR-LONG-SECRET-HERE
  4. Leave the window open (or set it up as a service — see docs/INSTALL.md §3).

You should see a line like KGPanel listening on :8080.

Did you see "listening on :8080"? If yes — the panel is running! Leave that window open and go to Step 3. If you instead see secret is required, you forgot to paste your secret — press Ctrl+C and run the command again with --secret filled in.

STEP 3Make your login (first time only)

Open your browser and go to: http://localhost:8080 (on the same computer). If the panel is on a different computer, use that computer's IP instead, like http://192.168.1.50:8080.

First time ever — the page shows a sign-up form. The very first account you make is the admin (the boss account). Use a password with 8+ characters.

The first thing you see. The setup box appears only while there are 0 accounts.
Did you get into the dashboard with menus on the left? If yes — you're logged in. Notice the top bar shows your name · admin.
Only the FIRST account made is admin. After that, everyone has to log in with a real account. If you ever see "login rejected", an admin already exists — use the account you made in this step.

STEP 4Install wings on the game computer

Wings is the helper that runs ON the computer with the games. That computer must have Docker installed.

No Docker? Install it first: Windows → Docker Desktop (turn it on and let it start). Linux → curl -fsSL https://get.docker.com | sh. Verify with docker --version in a NEW terminal window.

Pick a wing token (a password for the panel→wings connection). Make one up that's long and random, e.g. mywings-token-9x7q2. Save it — the panel needs it in the next step.

🪟 WINDOWS — start wings
  1. Make a folder: mkdir C:\ProgramData\wings
  2. Copy wings-windows-amd64.exe into it.
  3. In PowerShell (with Docker Desktop RUNNING):
    cd C:\ProgramData\wings
./wings-windows-amd64.exe --listen :8081 --token YOUR-WING-TOKEN --data .
  4. Leave it open. To make it a real Windows service, see docs/INSTALL.md §15.
🐧 LINUX — start wings
  1. sudo install -m 0755 wings-linux-amd64 /usr/local/bin/wings
sudo mkdir -p /var/lib/wings
  2. Run it:
    sudo wings --listen :8081 --token YOUR-WING-TOKEN --data /var/lib/wings
  3. Service version: see docs/INSTALL.md §7.

Test wings is up — in your browser: http://<game-computer-ip>:8081/v1/health. You should see {"status":"ok",...}.

Did you see "status":"ok"? Wings is alive and talking. If the browser won't open the page, wings isn't running or the firewall blocks port 8081 — check the wings window for errors.

STEP 5Connect the game computer to the panel

  1. In the panel (Step 3), click admin at the bottom of the left menu.
  2. Click the nodes tab (it's normally already open).
admin → nodes. Fill in: name (anything, like "my gaming pc"), the URL of wings, and the SAME wing token from Step 4.
BoxPut this
nameanything you'll recognise, e.g. gaming pc
urlhttp:// + the game computer's IP + :8081, e.g. http://192.168.1.50:8081
wings tokenthe EXACT same token you typed when starting wings in Step 4
The URL must be reachable from the panel's computer. Same house/same network usually works as-is. Use the computer's local IP (starts with 192.168. / 10. — not 127.0.0.1).
Clicked add and the node shows in the list? Good — panel and wings are connected.

STEP 6Add a game template (an "egg")

An egg = the recipe for running a game. In the panel: admin → eggs.

admin → eggs. This is where you tell the panel how to run your game.

Fill it in (example = PalWorld):

Egg saved and shows in the list? Good — you now have a game recipe.

STEP 8Open the server: power, console, live graphs

  1. On the server page, click the green ▶ (start) button. The first start downloads the game — it can take several minutes. Wait for the console to show the game's "server started" line (for PalWorld: Running Palworld dedicated server on :8211).
  2. Use ⟳ restart and ⬛ stop for those actions. The ⚠ kill button force-kills (last resort only).
The server page: green power button on top, four live graphs below (CPU, memory, network, disk), and the connect address for players.
  • Live graphs — CPU, memory, network, disk. They refresh every 5 seconds; the CPU one shows your game actually working.
  • Connect address — under the server name, e.g. 10.15.34.121:8211 (udp). This is what players type to join. Click copy to copy it.
  • Console — the game's text output, live. Type a command at the bottom and press Enter to send it into the game.
Started the game and the console shows it's running? You now have a live game server running in its own safe container. 🎉

STEP 9Change settings (ports, memory, CPU)

All settings live INSIDE the panel — no shell, no router, no SSH. Open the server → click the settings tab.

Server → settings. Edit memory, CPU, ports — then click "save & apply" and the panel rebuilds the game container with the new settings (the game stays running).
  1. Change memory / CPU / ports to what you want.
  2. Click save & apply.
  3. The panel rebuilds the container with the new limits — a few seconds, and the game restarts with the new settings.

Below it, the egg box edits the game template itself (image, startup, stop, ports, variables) — affects every server using that egg.

Saved a change and the game still came back up? The rebuild worked. If the game doesn't restart, click ▶ start again.

STEP 10Give a game its own database (FiveM and friends)

Some games keep their world saves in a database instead of files — FiveM (with the popular oxmysql/mysql-async scripts), MySQL-vaulted Minecraft, and similar. KGPanel has a built-in database switch: tick one box and it runs a private MariaDB on the same computer, makes a fresh database + username + password for that game, and hands them to the container as KG_DB_* settings.

Your database stays on the same machine as the game (private Docker network kggames-net) — it is never exposed to the internet, and it doesn't touch your domain or SSL. That's the whole point: same box, Docker, no outside access.
Admin → eggs. The "needs a database" box + docker network field (put kggames-net).
  1. Admin → eggs → click the pencil (edit) on your game's template — or make a new egg.
  2. Tick ☑ needs a database.
  3. For docker network put kggames-net (the built-in shared DB network). Save.
  4. In the game's console/startup config, use these environment variables it now receives: 
    KG_DB_HOST     = db          (the database server — same computer!)
KG_DB_PORT     = 3306
KG_DB_NAME     = kg_<server id>
KG_DB_USER     = kgu_<server id>
KG_DB_PASSWORD = (random, per server)
  5. For FiveM's server.cfg: set mysql_connection_string "mysql://<user>:<password>@db:3306/<database>?charset=utf8mb4".
  6. Start the game. The first start takes an extra minute while the database spins up — after that it's automatic every boot.
Restarted the game and the console shows it connecting to db:3306 without errors? You have a database. 🗄️
Only tick "needs a database" for games that actually use one. Games that save to files (like PalWorld) don't need it — unticked eggs run exactly as before, no DB container involved.

STEP 11Put it on the internet — your own domain + SSL

Right now the panel is on your local network. To open it from anywhere with https://yourname.com and the padlock, use a free Cloudflare tunnel. It doesn't touch your router at all, and SSL is automatic.

You need: (1) a domain that's on Cloudflare (free at cloudflare.com), (2) an API token with zone-edit permission (Cloudflare dashboard → My Profile → API Tokens → Create Token → use the "Edit zone DNS" template), (3) your Cloudflare account ID (same page, top right).

Then ONE command from a terminal on the panel's computer. Copy the one for your computer exactly, replacing the three YOUR bits:

🐧 LINUX / MAC
bash <(curl -fsSL https://raw.githubusercontent.com/MrKnuckls/kgpanel/main/deploy/kgpanel-cloudflare.sh) \
  --domain panel.yourname.com --cf-token "YOUR-TOKEN" --cf-account YOUR-ACCOUNT-ID
🪟 WINDOWS (no WSL needed)
powershell -ExecutionPolicy Bypass -File kgpanel-cloudflare.ps1 \
  -Domain panel.yourname.com -CfToken "YOUR-TOKEN" -CfAccount YOUR-ACCOUNT-ID

It checks your token → finds your domain → makes the tunnel → adds the DNS record → points your domain at your panel → installs the little tunnel helper so it starts automatically → checks the URL.

Pro tip: add --access your@email.com to the command and Cloudflare will ask for that email's login code before showing the panel (this is what you see below):

With --access, this is the Cloudflare login screen people see first. No email = no panel.
Opened https://panel.yourname.com in your phone browser (data/WiFi, not the panel computer) and saw the padlock + login? You're on the internet. 🎉
The tunnel exposes only the PANEL. Your game ports (like 8211) stay local unless you forward them — that's the safe default. See docs/INSTALL.md §11 for the no-script dashboard version of this step.

STEP 12If something looks wrong

What you seeWhat it means / do this
Panel window says secret is requiredThe secret wasn't passed. Re-run the start command with --secret + your saved secret.
Server badge says unreachablePanel can't reach wings. Check the wings URL in admin → nodes, and that wings is still running (firewall port 8081).
Badge says missingThe game's container hasn't been made yet — click ▶ start once so wings builds it.
Graphs empty / badge says unreachable right after updatingQuick fix: restart the panel process once (it sometimes keeps an old connection to wings).
Console says disconnectedWings is down, or the game container is stopped. Start wings, then start the game.
Sign-up form is gone / login rejectedAn admin already exists. Use YOUR account from Step 3.
docker: executable file not foundDocker isn't installed or not on PATH on the wings computer. Install Docker / Docker Desktop and restart wings.
Not sure what version you're onadmin → updates shows it, and even self-updates with one click.
